# To-Do-List
User can add tasks to a list, view all tasks, or exit

Inputs:
- what task
- task name

Outputs:
- List of tasks

Ex:
- input: add
- input: walk dog
- input: add
- input: feed cat
- input: add
- input: take Gerry swimming
- input: view
- output: walk dog, feed car, take Gerry swimming
- input: quit
